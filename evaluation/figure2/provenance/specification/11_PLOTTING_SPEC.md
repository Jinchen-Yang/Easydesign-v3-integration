# Plotting Specification

保持 Nature/Cell 风格，减少 dashboard 感。

## 2a
violin + box + raw points
y = turnaround time，log scale
x = target family / method

## 2b
aligned readouts：
completion / first-pass-valid / intervention

## 2c
per-target paired HQ-yield points + forest plot

## 2d
3 个 key metric distributions + quality-diversity scatter/Pareto

## 2e
target × method HQ-yield heatmap + family annotation

## 2f
non-GPCR paired-effect forest plot + pooled estimate

## 2g
fault type × method heatmap，或 correct-stop/recovery/false-completion bars

## 2h
traceability / approval / replay / lineage grouped bars + CI

不要：
- radar chart 作为主要定量图
- 3D
- 过厚柱子
- candidates 当独立 N
- 满图 p-value

最好：
raw target/run points、paired lines、95% CI、effect size。
