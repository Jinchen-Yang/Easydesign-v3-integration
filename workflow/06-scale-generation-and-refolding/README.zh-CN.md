# 06 — 放大生成与高精度复折叠

        [English](README.md) · [契约](CONTRACT.zh-CN.md)

        ## 目的

        放大入选策略，并通过通用结构预测后端评估候选。

        ## 支持场景

        - 使用显式规模预算，沿用同一可追溯执行契约进行放大。
- 在昂贵预测前规范化并去重候选。
- 准备、执行和收集通用复合物结构预测请求。

        ## 边界

        本阶段只负责声明的转换和输出校验。外部工具通过 backend adapter 访问。
        Orchestration、UI 行为和下游科学决策不属于本阶段。

        ## 非目标

        - 把 50,000 个设计硬编码到阶段契约。
- 把契约绑定到 Phoenix、AFO、AF3 或任何单一模型品牌。
- 把模型 ranking score 当成最终下单批准。

        ## 实现状态

        `planned`。本目录只规定预期行为；存在这些文档不代表科学实现已经完成。
