# EasyDesign

[简体中文](README.zh-CN.md)

EasyDesign is a contract-first, seven-stage workflow for traceable VHH binder
design. This repository is a clean-room foundation: it defines boundaries,
artifacts, provenance, and engineering rules before implementing scientific
backends.

**Current version:** `0.1.0-dev` (`0.1.0.dev0`)

**Current status:** repository foundation is `implemented`; scientific stages
remain `planned`. No design generated by this repository should currently be
interpreted as experimentally or scientifically validated.

## The seven stages

| Stage | Responsibility |
| --- | --- |
| `01-target-preparation` | Resolve six target input routes into one canonical Target Bundle. |
| `02-hotspot-discovery` | Produce evidence-linked hotspot candidates and avoid regions. |
| `03-boltzgen-configuration` | Build and validate VHH-focused BoltzGen strategy YAML. |
| `04-pilot-generation` | Run a small, fully traced BoltzGen pilot. |
| `05-pilot-filtering` | Apply system-specific, versioned filters to pilot candidates. |
| `06-scale-generation-and-refolding` | Scale selected strategies and evaluate them through a replaceable structure-prediction backend. |
| `07-final-filtering-and-selection` | Rank, diversify, package, and audit the final Top N candidates for human approval. |

Human-readable stage specifications live in [`workflow/`](workflow/README.md).
Python implementations will mirror them under `src/easydesign/stages/`.

## Repository principles

- One source of truth for every scientific or software concept.
- Explicit manifests between stages; no path guessing or silent fallback.
- Scientific logic belongs in the Python API, never in CLI, UI, or shell wrappers.
- Software completion and scientific success are reported separately.
- Runs, model weights, secrets, and unreviewed third-party assets are never committed.

## Development

The core package targets Python 3.11. Heavy scientific tools run behind adapters
and may use separate environments.

```bash
make check PYTHON=/path/to/python3.11
make test PYTHON=/path/to/python3.11
make build PYTHON=/path/to/python3.11
```

This private development repository intentionally has no public license, CLI, UI,
or configured Git remote at this stage.
