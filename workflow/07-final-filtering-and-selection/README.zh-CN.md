# 07 — 最终筛选与候选选择

        [English](README.md) · [契约](CONTRACT.zh-CN.md)

        ## 目的

        应用最终证据规则、保留多样性，并为人工批准打包可审计 Top N。

        ## 支持场景

        - 应用最终结构、界面、置信度、clash 和体系专属门槛。
- 按声明的多样性规则对通过候选排序和聚类。
- 打包序列、结构、指标、警告和溯源供审核。

        ## 边界

        本阶段只负责声明的转换和输出校验。外部工具通过 backend adapter 访问。
        Orchestration、UI 行为和下游科学决策不属于本阶段。

        ## 非目标

        - 在 EasyDesign 1.0 自动发送合成订单。
- 为了凑满 Top N 而隐藏负面或不确定证据。
- 宣称入选候选已经通过实验验证。

        ## 实现状态

        `planned`。本目录只规定预期行为；存在这些文档不代表科学实现已经完成。
