# 04 — 小批量生成

        [English](README.md) · [契约](CONTRACT.zh-CN.md)

        ## 目的

        执行真实、小批量的 BoltzGen pilot，并保留完整任务与环境溯源。

        ## 支持场景

        - 在已校验策略之间规划有边界的小批量预算。
- 通过 executor adapter 提交并收集任务级状态。
- 在不修改后端原始产物的前提下规范化成功候选。

        ## 边界

        本阶段只负责声明的转换和输出校验。外部工具通过 backend adapter 访问。
        Orchestration、UI 行为和下游科学决策不属于本阶段。

        ## 非目标

        - 生产规模生成。
- 筛选或宣布科学赢家。
- 只报告成功任务从而隐藏部分失败。

        ## 实现状态

        `planned`。本目录只规定预期行为；存在这些文档不代表科学实现已经完成。
