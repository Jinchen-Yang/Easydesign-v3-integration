## 尚未覆盖的容量与发布条件

1. 300 个不同账户在固定一分钟内登录的测试使用 8 个线程及真实密码派生，
   验证共享来源不会因成功登录耗尽失败额度；**不是 300 个同时在途 HTTP 请求的性能测试**。
2. 登录默认最多 8 个同时密码校验、300 个等待校验、等待超时 10 秒。
   这个限制只覆盖密码校验阶段，不覆盖全部 HTTP 连接或校验后的 SQLite 写入等待；
   仍需基于实际负载测量延迟、调整准入策略。
3. 来源仍使用 TCP peer；可信代理与真实客户端地址处理未在本批实现，
   反向代理后的错误登录仍可能共享失败额度。
4. AI 请求限额/排队、GPU 任务公平调度、后端上传、真实模型执行，以及
   300 人混合流程、网络带宽与 CDN 效果的验证均尚未完成。
   浏览器选择 FASTA 仅验证前端解析，不是后端上传或设计任务测试。
5. 发布前必须补齐跨版本旧哈希资源可访问性及回滚验证，具体约束见部署基线；
   仅留下旧 release 目录不能保证旧页面的延迟加载脚本还能访问。
6. 无科学执行器的浏览器 fixture 中，Agent Workspace 空状态仍显示可点的
   `Start design`，而 Projects / Easy 已禁用创建。未点击，未证实权限绕过；
