## 2026-07-25 — S02-003 / S02-004：多模型 SASA、可选注释与审批交接

- 状态：`smoke-validated`
- 完成时间：2026-07-25T11:37:25+08:00
- 提交：`f30205d8a10c837ac4e437639800d1d811d41929`
- 完成边界：实现多模型 SASA 共识、显式 UniProt annotation policy、等待人工批准状态
  和不可变 `hotspots.yaml` 交接；不替用户批准真实 APOE 区域，不实现 ScanNet ensemble、
  自动身份发现、PSE/manual 区域输入或外部 pocket 模型。

### 完成内容

- SASA 对每个 coordinate model 独立计算 raw SASA、rSASA、presence、暴露和邻接边，再以
  70% presence/exposure/edge/region 完整度、中位数指标和最坏情况区域分离形成共识。
- 单模型是 N=1 特例；ScanNet 遇到多模型时明确返回 `unsupported_ensemble`，不会选
  代表 model、平均概率或回退 SASA。
- UniProt 支持 `off/if_available/required`；只有显式 accession 才联网，确定性映射
  active/binding/site/domain/PTM/topology feature，N-X-S/T 只作为潜在 motif warning。
- 自动 run 结束后保持 `running / awaiting-human-approval`；审批只能从同一种方法选择
  2–3 个完整区域，核对源 StageManifest/region SHA-256，并用新 attempt 发布唯一
  `hotspots.yaml`。structural-only 必须确认 evidence limitations。

### 验证证据

- 10 模型 fixture 验证 7/10 支持通过、6/10 失败；覆盖模型缺失、残基类型冲突、中位数、
  edge `ceil(N×0.70)` 和中心距离/shell/重原子距离的保守最坏情况。
- annotation 测试证明空 accession 零网络请求、显式 accession feature 回映射和低 identity
  review；审批测试覆盖 acknowledgement、跨方法、成员篡改和旧 revision 拒绝。
- 真实 runtime-only APOE validation：
  `/root/autodl-tmp/Protein_design/easydesign-clean-validation.lDkLYp/`。run
  `20260725-001-v03-pse` 使用 canonical schema 0.3、138-aa PSE、SASA 和 ScanNet CPU，
  发布完整两套候选与 comparison，annotation 为
  `not_requested / structural_only`，Viewer 成功并停在人工批准状态。
- `hotspots export --method sasa` 成功生成审批模板，包含源 StageManifest 和 region
  artifact SHA-256；未填写理由的模板没有被伪装成批准结果。

### 遇到的问题

- 旧代码把所有 model ID 非 `1` 的结构直接拒绝，无法区分 adapter 能力限制与通用科学
  数据契约。
- 缺少 accession 时若输出空 `functional_sites`，会错误暗示已经联网查询且没有发现；
  自动 Top 3 若直接作为 handoff，又会把工程候选伪装成科学批准。
- 新 Viewer schema 增加模型字段后，浏览器 fixture 未同步，首次 web gate 在 fixture
  构造阶段明确失败。

### 解决办法

- 结构解析按模型保留坐标和缺失证据，残基身份通过共享 label 编号校验；SASA 共识只使用
  达到支持率的残基、边和区域。
- annotation 使用 `not_requested/not_implemented/failed` 等显式状态；排名与证据完全
  分离。RunManifest 1.2 独立表达等待人工动作，Stage 03 只能读取批准 attempt 声明的
  `hotspots.yaml`。
- 补齐 Viewer fixture 的单模型 descriptor 后重跑 Playwright，结果为 3 passed、
  2 skipped；完整 Python 门禁为 151 passed、8 skipped。

### 遗留问题

- S02-005 等待用户对真实 APOE 的 SASA/ScanNet Top 3 做科学判断并批准；自动结果与合成
  审批测试都不能代替该决定。
- ScanNet ensemble、自动 UniProt identity、天然复合物界面、文献/疾病突变、
  PSE/manual provider、SASA 归一化来源 benchmark 和 VHH–抗原科学 benchmark 仍待完成。
- ScanNet GPU 在 RTX 4080 的真实模型推理仍失败；CPU 是当前主线，GPU 只作为后续性能
  优化，不阻塞 Stage 03。
