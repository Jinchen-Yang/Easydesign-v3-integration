### 遇到的问题

- Protenix 2.0.0 包内 checkpoint URL 返回 HTTP 403。
- 首次运行缺少可供 CUDA JIT 扩展使用的 `nvcc` 和开发库。

### 解决办法

- 将 checkpoint 获取作为独立 runtime 资产：使用可访问备份恢复，校验 SHA-256 并完成
  PyTorch CPU 反序列化；在官方来源可复核前只批准内部 runtime 使用。
- 在 Protenix 独立 Conda 环境固定 `cuda-nvcc 12.6.85` 和
  `cuda-libraries-dev 12.6.3`，成功编译 LayerNorm CUDA 扩展。
- 为两个 MSA 服务分别创建不可覆盖 attempt；达到工程超时后写入
  `failed`、`retryable=true` 和明确失败原因，没有伪造成功或回退。
