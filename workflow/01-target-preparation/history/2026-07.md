## 2026-07-24 — S01-004：APOE 单 Target PyMOL PSE 导入

- 状态：`smoke-validated`
- 完成边界：可信本地、单蛋白 molecule object、单条非空 protein chain、单 coordinate
  state 的 PSE 直接导入 imported Target Bundle；不包含复合物、配体保留、公开上传、
  人工 object/chain/state 选择或 hotspot 解释。

### 完成内容

- 创建独立 Python 3.11 / `pymol-open-source=3.1.0` Conda 环境；core 不安装或导入
  PyMOL，只通过显式 Python 路径和 JSON/PDB 文件协议调用 worker。
- 将用户 YAML 拆成排他的 sequence 与 PSE 类型分支；PSE 禁止
  `structure_prediction`，sequence/FASTA 继续要求显式预测配置。
- 实现严格 session inventory、标准残基/CA/author numbering 校验、PDB 到规范 mmCIF
  转换、连续 label 编号、imported quality/provenance 和逐残基 CA 颜色 annotation。
- Target Bundle 升级到可选 `source_annotations` 的 0.2，同时保留 0.1 读取兼容。
- 发布 Attempt、StageManifest、RunManifest revision 和 `LATEST`，并更新 run index。

### 验证证据

- 合成 PSE 成功路径和零蛋白、多 object、多 chain、多 state、配体、非标准残基、损坏 PSE
  失败路径均在独立 PyMOL 环境通过；timeout、非零退出和输出缺失由 adapter 测试覆盖。
- APOE runtime-only fixture：397,738 bytes，SHA-256
  `7d382a2fd158bd4664ef3d17296591e380ff01232926ed5bc86a9bcd7a813651`。
- 正式 run：`runs/apoe/20260724-002-stage01-pse`；object `1B68`、chain `A`、state 1、
  138 个残基、sequence SHA-256
  `f805c6ca91a7d925814212be97c34f0de339067c8a7ade2826dd5168da6bd2af`。
- CA 颜色计数为主色 101、red 9、blue 14、yellow 14；颜色保持
  `uninterpreted`，未运行 Protenix、MSA 或结构预测。
- `make check`、`make test`、`make build`、PyMOL import 和真实 PSE 集成测试通过。

### 遇到的问题

- PyMOL headless 初始化后，短命 Python 进程必须显式 flush/quit 才能可靠返回版本文本。
- PyMOL `Atom` 对象不直接暴露有效的动态 `color` 字段；颜色需要通过 `cmd.iterate`
  按 `(model, atom index)` 收集。
- 从 PDB 建立的 Gemmi entity 缺少 full sequence，初次 mmCIF 的 `label_seq_id` 为空。
- PyMOL 在部分 worker 失败时会以进程码 0 退出，但留下机器可读的失败 response。

### 解决办法

- 版本探针显式写 stdout、flush 并退出 PyMOL，且必须精确匹配 `3.1.0`。
- worker 用 `cmd.iterate` 取得逐 CA color index，再解析 RGB/hex 并校验颜色计数。
- core 从已验证的标准残基顺序补全 entity sequence，再生成连续 `label_seq_id` 的 mmCIF。
- adapter 同时检查进程码和 response `status/error_code`，成功退出但失败 response 仍按失败
  处理；没有 fallback。

### 遗留问题

- PSE 当前被视为可信本地输入；UI 公开上传前需要独立安全沙箱和资源限制。
- 复合物、receptor/ligand、多聚体、非标准残基、配体保留和人工选择必须通过新契约实现，
  不能放宽当前单 Target 规则。
- PSE 颜色只是一项用户来源 annotation；Stage 02 必须独立记录将其转成 hotspot 证据的
  方法、规则和置信度。
