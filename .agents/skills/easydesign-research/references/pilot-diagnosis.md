# Pilot diagnosis

Each pilot is a new immutable run derived from one approved foundation and one frozen strategy. A
negative pilot is valid completed evidence, not an operational failure.

Review structured pass rates by strategy, failures by filter rule, representative structures, backend
diagnostics and comparable metrics. Distinguish generation shortfall, structural quality, interface
geometry, fold/refold inconsistency and filter-threshold effects. Do not infer causality from one metric
or silently relax the frozen filter standard.

Record the hypothesis and evidence in `DECISIONS.md`, then draft a new strategy revision. Never rewrite
the previous run. Promotion is a human decision and may select one or more checksum-verified strategies;
filter success alone cannot promote them.
