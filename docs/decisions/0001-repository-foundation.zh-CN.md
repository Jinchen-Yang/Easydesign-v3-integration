# ADR 0001：全新、契约优先的仓库基础

[English](0001-repository-foundation.md)

- 状态：Accepted
- 日期：2026-07-23

## 背景

旧仓混合了重复 package、UI 关注点、执行环境假设和科学流程逻辑。持续在旧仓清理，
容易保留不清晰的所有权和误导性状态。

## 决策

从零建立新的私有仓库。采用七个稳定编号工作流目录、镜像的合法 Python package 名、
不可变 manifest 交接、可替换后端、双语规范文档和 Python-API-first 产品路线。
旧仓保持只读参考。

## 后果

有用的旧仓思路必须有意识地重新实现；只有审查后才能迁移。初期看起来更慢，但边界、
溯源、验证和未来 CLI/UI 复用将可强制执行。当前不配置公开许可证或 Git remote。
