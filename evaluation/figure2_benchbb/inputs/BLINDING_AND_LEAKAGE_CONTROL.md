# Blinding and leakage control

The resource library contains researcher-facing background that can bias site choice. For a fair fresh benchmark:

1. Place the evaluated agent in a clean project/session with no earlier NK2R or target-specific run history.
2. Provide only the task statement and the declared input structure/source policy.
3. Do not expose this directory's challenge descriptions, target priorities, known binding clefts, literature hit rates, prior outputs, or manually curated hotspots.
4. Permit only the same declared search and structure tools for systems assigned the same tool condition.
5. Freeze the system commit before measured trials.
6. Log all human repairs and exclude development runs from the final first-pass statistic.
7. Score objective contracts deterministically; blind qualitative reviewers to method identity where feasible.

Public training-data exposure cannot be eliminated for natural proteins. BBF-14 is useful as a newer non-natural target, but its public structure and papers still require an explicit benchmark cutoff and model-release disclosure.
